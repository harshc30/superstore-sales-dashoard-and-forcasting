
# 📊 Superstore Sales Dashboard & Forecasting – Power BI

An interactive Power BI dashboard built using the Superstore dataset to analyze sales, profit, customer segments, product performance, and regional trends.

## 🚀 Project Overview

This project focuses on transforming raw Superstore sales data into meaningful business insights through interactive dashboards and forecasting.

The dashboard provides a comprehensive view of business performance and helps identify trends, top-performing products, profitable regions, and customer behavior.

## 🔍 Key Features

- 📈 Sales and Profit Analysis
- 💰 KPI Tracking for Sales, Profit, Orders, and Quantity
- 🌎 Regional and State-wise Performance Analysis
- 👥 Customer Segment Analysis
- 📦 Product Category and Sub-Category Analysis
- 📅 Time-Series Sales Analysis
- 🔮 Sales Forecasting for Future Trends
- 🎛️ Interactive Filters and Slicers
- 📊 Dynamic and Interactive Visualizations

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Forecasting
- Superstore Dataset

## 🎯 Objective

The main objective of this project is to analyze historical sales data, identify important business trends, and use forecasting techniques to estimate future sales performance.

This project demonstrates practical skills in **Data Analysis, Business Intelligence, Data Visualization, Power BI, and DAX**.
